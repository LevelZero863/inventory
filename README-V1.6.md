# 库存管理系统 V1.6

## Excel 批量导入

系统提供统一的 `库存系统批量导入模板.xlsx`，包含以下工作表：

- 产品：按产品编码新增或更新；
- 客户：按客户编码新增或更新；
- 仓库：按仓库编码新增或更新；
- 入库单：相同导入单号的多行合并成一张正式入库单；
- 出库单：支持销售出库和领料出库，继续执行库存校验；
- 结算单：按客户和销售出库单核销应收；
- 库存：以目标库存生成差额调整流水，不覆盖历史记录。

导入流程统一为“下载模板 → 上传文件 → 数据预览 → 勾选确认 → 执行导入”。单次最多 5000 行、文件不超过 10 MB。系统校验表头、日期、数值、状态、主数据引用、库存和结算额度，并记录完整审计日志。

## 仓库基础资料

- 基础资料新增“仓库管理”页；
- 仓库包含编码、名称、状态和备注；
- 停用仓库不能用于新建单据或 Excel 业务导入；
- 已发生业务的仓库不能改名，避免历史库存按名称断裂；
- V1.5 既有仓库在迁移时自动生成 `WHxxx` 编码，ID、名称和历史业务数据保持不变。

## 界面升级

界面采用成熟进销存产品常见的信息架构：

- 深蓝色模块导航与清晰的岗位入口；
- 浅色业务工作区和统一页面标题横幅；
- 经营指标卡、紧凑筛选区、白色数据表面板；
- 主操作与次操作分级，Excel 导入入口统一折叠；
- 页面文字强调业务结果、状态和下一步操作。

## 权限与审计

- 管理员：导入产品、客户和仓库；
- 仓库人员：导入入库单、出库单和库存盘点；
- 财务人员：导入结算单；
- 只读人员：不能执行任何导入；
- 所有导入新增、更新和库存调整均进入审计日志。

## 数据升级

`005_warehouse_master.sql` 采用增量迁移，只为仓库增加编码、状态和备注字段及查询索引，不删除、不重建业务表。执行正式迁移前仍会自动备份数据库。
