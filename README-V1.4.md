# 库存管理系统 V1.4

## 权限体系

系统内置四类角色，并同时在界面层和服务层校验权限：

- 管理员：基础资料、入库、出库、结算、单据作废、用户权限、备份和审计日志。
- 仓库人员：查看业务数据，新增入库单和出库单。
- 财务人员：查看业务数据，新增及作废结算单。
- 只读人员：仅查看首页、单据、应收和库存数据。

管理员可以创建、停用用户，调整角色及重置密码。系统禁止停用当前账号，并确保至少保留一个启用的管理员。

## 单据生命周期

- 新建入库单、出库单和结算单仍然提交即生效，不恢复草稿状态。
- 已生效单据不能直接修改或删除，只能填写原因后作废。
- 作废入库单生成负向库存流水；若相关库存已经被使用，则拒绝作废。
- 作废出库单生成正向库存流水；已有结算时必须先作废关联结算单。
- 作废结算单自动恢复对应出库单的未收金额。
- 原单据、原明细、作废原因、作废人员和反向流水永久保留。

## 完整审计日志

独立审计表记录以下操作：

- 登录成功、登录失败和退出登录；
- 用户创建、权限调整、密码修改及管理员重置密码；
- 产品和客户的新增、修改及状态变化；
- 入库、出库、结算单生效和作废；
- 手工数据库备份。

涉及数据修改的日志保存修改前、修改后快照。审计页面只对管理员开放，日志不可在系统内编辑或删除。

## 数据升级

升级通过 `003_permissions_lifecycle_audit.sql` 增量迁移完成。迁移前自动备份现有数据库，不删除或覆盖历史业务数据。旧版本的普通 `user` 角色自动转为只读角色。
