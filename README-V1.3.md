# 库存管理系统 V1.3

## 本版本更新

- 产品列表全部中文化，产品编码、名称、规格、单位、默认单价、状态和备注均可直接编辑。
- 客户资料同样支持直接编辑，并统一中文字段和状态控制。
- 新建入库单、出库单时，切换产品会自动带出该产品的默认单价，仍允许按本次业务调整。
- 入库单和出库单明细支持新增、删除多行，并实时计算各行金额和单据总金额。
- 入库单、出库单、结算单列表全部中文化，金额字段统一按人民币格式显示。
- 应收账款按客户汇总，点击客户行可查看对应出库单明细。
- 停用产品不再用于新建入库、出库；停用客户不再用于新建出库，但历史应收仍可正常结算。
- 重复产品编码、客户编码会显示中文提示。
- 首页、库存、待结算及应收页面补充空数据提示和一致的中文显示。

## 数据安全

本版本仅调整程序和界面逻辑，不覆盖现有 `data/inventory.db`。数据库迁移继续沿用自动备份机制。
