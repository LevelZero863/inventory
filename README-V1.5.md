# 库存管理系统 V1.5

## 单据 PDF 与打印

- 在入库单、出库单、结算单列表中点击一条记录，可下载对应的标准 A4 PDF。
- 下载后可用浏览器或系统 PDF 查看器直接打印。
- PDF 包含单号、日期、业务对象、经办人、状态、明细、合计、备注和签字栏。
- 多行明细会自动分页，并在每页重复表头。
- PDF 内嵌 Noto Sans SC 中文字体，不依赖使用者电脑是否安装中文字体。
- 下载 PDF 的动作写入审计日志。

## 多字段筛选

- 入库单：入库日期、仓库、状态、单号/供应商/经办人关键词。
- 出库单：出库日期、仓库、状态、出库类型、单号/客户/领料人/经办人关键词。
- 结算单：结算日期、状态、客户、单号/客户/经办人关键词。
- 库存：仓库、产品编码/名称/规格关键词、仅显示非零库存；可按截止日期查询历史时点库存。

日期筛选默认关闭，避免升级后隐藏已有历史单据。

## 领料出库

- 新建出库单时可选择“销售出库”或“领料出库”。
- 领料出库不需要填写客户，可选填领料人或部门。
- 领料出库提交即生效并减少库存，但不生成应收账款，也不能进入结算单。
- 领料出库仍保留金额，便于记录内部领用成本。
- 领料出库可以按原有生命周期规则作废，作废时生成正向库存流水。

## 数据升级

升级使用 `004_material_issue_and_filters.sql` 增量迁移：

- 只为出库单增加 `outbound_type` 和 `material_recipient` 字段；
- 既有出库单自动标记为“销售出库”，原应收与结算关系不变；
- 新增查询索引，不删除、不重建、不覆盖任何业务表；
- 内部领料系统客户仅在首次领料出库时按需创建，并在客户资料界面中隐藏；
- 执行迁移前系统仍会自动备份正式数据库。
